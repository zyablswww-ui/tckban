# TCK Ban (Fabric 1.21.4)

Когда админ банит игрока (`/ban`, `/ban-ip`):

1. кик откладывается, игрок замирает;
2. приезжает бусик (собран из block_display, клиентский мод не нужен);
3. из него выходят двое «ТЦК» (armor_stand в зелёной броне), берут игрока под руки;
4. тащат к задней двери, запихивают в багажник, садятся и уезжают;
5. проехав 5 блоков, бусик исчезает в клубах дыма, и только тогда игрок реально кикается с причиной бана.

Нужен только на сервере. Требует Fabric Loader + Fabric API для 1.21.4.

## Сборка

Нужен JDK 21.

Gradle wrapper в архив не включён. Проще всего: скачай https://github.com/FabricMC/fabric-example-mod
(ветка 1.21), скопируй из него папку `gradle/` и файлы `gradlew`, `gradlew.bat` сюда. Затем:

    ./gradlew build

Готовый мод: `build/libs/tckban-1.0.0.jar` -> в папку `mods` сервера.

## Настройки

Константы сверху `src/main/java/ru/tckban/TckSequence.java`:
расстояние старта, скорость, сколько блоков проезжает до исчезновения и т.д.
Внешний вид бусика — массив `PARTS` там же.

## Известные ограничения

- Бусик не проверяет препятствия: в тесных местах/под землёй он может ехать сквозь блоки.
- Если игрок сам отключится посреди сцены, всё убирается.
